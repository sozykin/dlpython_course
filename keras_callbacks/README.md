# Callback'и в Keras и TensorFlow

[Callback](https://keras.io/api/callbacks/) - это объект, который может выполнять определенные действия на определенных этапах обучения, например, в конце каждой эпохи.

## Примеры использования Callback

- `saving_models.ipynb` - сохранение модели в процессе обучения (на каждой эпохе или только лучший вариант модели).
- `early_stopping.ipynb` - остановка обучения при возникновении переобучения.
- `lr_scheduler.ipynb` - управление параметром скорости обучения во время обучения нейросети.
- `history.ipynb` - объект `history`, с помощью которого мы выводим графики обучения, тоже создается [callback'ом](https://www.tensorflow.org/api_docs/python/tf/keras/callbacks/History). В отличие от других callback'ов, он вызывается автоматически. Исследуем, как устроен объект History.
